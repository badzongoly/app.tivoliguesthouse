# Stock Counts and Variance Review

Open **Extras & Stock > Stock Counts & Variance Review**.

## Count stock

1. Select Start Count, choose the purpose and up to 50 tracked items. Inactive tracked items can still be counted.
2. For each item, select Begin Counting immediately before physically counting it. Count saleable quantities in the shared stock locations. Describe damaged/expired quantities held separately in the optional Count Note; keep those goods secured.
3. Enter the actual quantity and save. Quantities support hundredths for existing fractional stock. Expected balances remain hidden until every selected item is complete.
4. If stock moves during an item's counting window, begin that item again and physically recount it. Sales are not globally blocked; coordinate briefly with the cashier where practical.
5. Review the comparison, select a reason and explain every difference. Optional evidence for the submission accepts PDF/JPEG/PNG up to 2 MB.
6. Confirm and submit for Eugene's review. Submission does not change inventory.

An unfinished count can be cancelled. Its evidence stays in history. After submission, use clarification or a linked recount; do not replace the original.

## Eugene reviews

Owner Review lists submitted counts, disputes and requested recounts. Check the physical evidence, original sales and deliveries before deciding.

- **Approve:** verify the displayed differences and add a decision/investigation note. Approval adds only each difference to the latest recorded balance, retaining later sales and deliveries. It creates one linked movement for each non-zero difference. A matching count records review without a movement.
- **Dispute:** give the reason. The counter can append clarification and optional evidence; the original declaration stays visible.
- **Request Recount:** give instructions. The original counter starts a new linked count of the same items. The original is superseded only when the new count is submitted. Cancelling an unfinished recount leaves the original request open.
- If Eugene counted personally, an explicit self-review exception reason is required.

Normal sales/deliveries after counting remain in the calculation. If balances change after preview, reload and review again before approval. Another adjustment, unsupported evidence or an unexplained balance change requires investigation and a fresh count, not a guessed repair. Negative resulting balances are rejected.

Check whether a missing sale or receipt should first be recorded through its proper authorized workflow. A quantity adjustment must not conceal unrecorded revenue, bypass purchasing or record the same loss twice. Approval alone creates no expense, payment, staff deduction, valuation or disposal permission.

## History and unavailable comparisons

Show Details retains identities, UTC timestamps, counts, explanations, decisions, approval snapshots, linked stock movements and recounts. Requester and configured finance owner alone can open private count details/files. Other staff can receive a handover task link without gaining access to private evidence.

If an old item is no longer tracked or its current movements cannot be compared safely, original evidence remains readable. Current values show Unavailable, and adjustment approval is blocked. Database outages remain errors rather than guessed quantities.

Existing stock history remains available. The former public immediate stock-count form redirects here and its submissions are denied. Do not use old writers alongside this workflow.

Correct an approved count through a new evidenced count and review; do not edit/delete its movement. Reassigning a submitted count to another counter, financial write-offs, valuation, loss deductions and external notification delivery are outside this version. Owner attention and shift handover provide in-app follow-up.
