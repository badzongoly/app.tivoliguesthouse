## Implementation rulings
Approved scope is guest receipts only. Corrections post in today's open period, never change charge/revenue or send money. Original receipt rows and reference claims remain. Current source position is a projection over linked adjustments. Old locked-period receipt totals remain fixed; adjustment legs appear by posting date. A checkout annotation records the last included correction ID, avoiding same-second double counting in frozen bills. Sources with any deposit/handover allocation or matched wallet evidence require separate reconciliation before correction. Owner may approve own request under explicit authority. Subsequent corrections reference the current effective chain; no silent undo. A compensated duplicate remains linked to its retained collection and cannot be resurrected. Correct the retained receipt when supported; an incorrect duplicate determination requires separate evidenced reconciliation. Immutable alias claims resolve through the retained collection chain.
